# Regras para o Assistente

## Regra Fundamental
Nunca delete código existente. Este é um projeto em produção.

## Modificações
- Toda modificação deve ser **autorizada** pelo usuário antes de ser executada
- Nunca tome iniciativa própria para alterar, deletar ou modificar arquivos
- Sempre explique o motivo da modificação e peça autorização

## .env
- **NUNCA** mexer no arquivo `.env`

## Header e Estilos
- Não alterar cores, estilos ou layout do header a menos que explicitamente solicitado
- Não adicionar ThemeProvider, ThemeColorPicker ou qualquer sistema de temas sem autorização

## Escopo
- Fazer apenas o que foi pedido, sem "extras" ou melhorias não solicitadas
